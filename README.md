# NONI Portfolio v2
Обновлённый адаптивный шаблон: Vanilla JS + Three.js + GSAP.

## Что изменилось
- удалён фоновый word-cloud;
- верхняя sticky-панель получила разноцветные pill-кнопки в стиле конфет;
- 3D сильнее реагирует на движение мыши и получает дополнительный touch-отклик;
- подвал переделан в пастельную иллюстрированную сцену-сад, вдохновлённую приложенным референсом;
- сохранены мобильные стили и prefers-reduced-motion.

## Запуск
Открой папку в VS Code и запусти Live Server. Или `python3 -m http.server 8000`, затем перейди на `http://localhost:8000`.
Не запускай напрямую через file://, потому что Three.js использует ES-модули.

## Как сделать 3D-голову
Сейчас используется процедурная геометрия Three.js. Для головы нужны:
1. 3D-модель головы в формате `.glb` или `.gltf` (сделать в Blender, заказать у 3D-художника или создать по 3D-скану/фотограмметрии с согласованными фото).
2. Подключить `GLTFLoader` из `three/addons/loaders/GLTFLoader.js`.
3. Загрузить модель в сцену вместо `TorusKnotGeometry`.
4. Для стилизованного вида можно использовать clay/chrome/toon-материал, а глаза/волосы/аксессуары оставить отдельными объектами.
5. Если нужно, чтобы голова была именно похожа на тебя, понадобится набор фотографий с разных ракурсов или собственная 3D-модель. Лучше не полагаться на одну фронтальную фотографию.
